# Customer Order Data Analysis

## Project Overview

This project demonstrates an end-to-end customer order data workflow using Python and Pandas. Raw customer order data is cleaned, validated, transformed, and analyzed to generate insights about revenue, customers, products, and order completion.

## Objectives

- Clean and prepare raw customer order data
- Validate data quality before performing analysis
- Analyze revenue by category and order status
- Identify top customers based on revenue
- Analyze product revenue and quantities sold
- Calculate key business metrics such as average order value
- Identify highest and lowest value orders
- Calculate customer-level order and revenue metrics
- Measure order completion rate

## Project Workflow

The project follows the workflow:

Raw Data → Data Cleaning → Cleaned Data → Data Analysis → Analysis Results

### 1. Raw Data

`orders.csv`

Contains the original customer order dataset used as the input for the project.

### 2. Data Cleaning

`data_cleaning.py`

Uses Python and Pandas to clean and validate the raw order data before analysis.

The cleaned dataset is saved as:

`cleaned_orders.csv`

### 3. Data Analysis

`data_analysis.py`

Loads the cleaned dataset and performs customer, product, revenue, and order analysis.

The analysis includes:

- Total revenue
- Revenue by category
- Revenue by order status
- Order count by status
- Revenue by customer
- Revenue by product
- Quantity sold by product
- Average order value
- Highest order value
- Lowest order value
- Number of unique customers
- Orders per customer
- Average revenue per customer
- Revenue percentage by order status
- Order completion rate

### 4. Analysis Output

`analysis_results.txt`

Stores the output generated by the Python analysis script.

## How to Run the Project

First, run the data cleaning script:

```bash
python data_cleaning.py
```

This creates the cleaned dataset.

Then run the data analysis script:

```bash
python data_analysis.py
```

To save the analysis output to a text file:

```bash
python data_analysis.py > analysis_results.txt
```
