# Customer Order Data Analysis

## Project Overview

This project analyzes customer order data to understand sales performance, customer purchasing behavior, and product trends.

## Objectives

- Clean and prepare raw customer order data
- Analyze customer purchases using SQL
- Use Python for data cleaning and analysis
- Identify top customers and products
- Analyze sales trends over time

## Tools Used

- SQL
- Python
- Pandas
- GitHub

## Dataset

The dataset contains customer order information including order ID, customer ID, product, category, quantity, price, order date, and order status.
